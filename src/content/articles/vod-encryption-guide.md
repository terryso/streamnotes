对于在线教育、企业内训和知识付费平台来说，视频就是核心资产。课程被下载、转卖，带来的不仅是收入损失，还可能导致内部资料外泄。本文梳理视频点播内容保护的常见做法，帮助你按业务需要组合方案。

> 只要视频能在屏幕上播放，就存在被录屏的可能。内容保护的目标是提高盗用成本，并在泄露后可追溯。

## 一、先明确目标：提高成本 + 可追溯

需要先接受一个事实：只要视频能在屏幕上播放，就存在被录屏的可能。因此内容保护的合理目标是两条：

1. **提高盗用成本**，让普通用户无法通过简单的下载工具拿到可播放的文件；
2. **泄露后可追溯**，能定位是哪个账号、在什么时间外泄的。

围绕这两个目标，可以搭建四层防线。

## 二、第一层：传输与存储安全

- **全站 HTTPS**：防止视频地址和密钥在传输过程中被嗅探。
- **存储桶私有化**：源文件存储设为私有读，只允许转码服务和 CDN 回源访问。
- **管理后台权限分级**：上传、审核、发布、删除等操作按角色授权，并记录操作日志。

这一层成本最低，却最容易被忽略。

## 三、第二层：分片加密

### HLS AES-128

HLS 标准（RFC 8216）通过 `EXT-X-KEY` 标签定义了加密方式。AES-128 模式会对整个分片做 AES-128-CBC 加密，播放器根据播放列表中的 `URI` 获取密钥后再解密播放。

```
#EXT-X-KEY:METHOD=AES-128,URI="https://key.example.com/getkey?vid=123&token=xxx",IV=0x...
```

它的优点是几乎所有支持 HLS 的播放器都能播放，接入简单。**关键风险在于密钥接口**：如果 `URI` 可以被任意访问，加密就形同虚设。正确做法是：

- 密钥接口校验登录态或一次性播放凭证（token），并设置较短的有效期；
- 不同视频使用不同密钥，必要时可以定期轮换；
- 播放器侧对密钥做混淆处理，避免明文出现在网络请求中。

### SAMPLE-AES

SAMPLE-AES 只加密音视频样本数据，容器结构保持明文，常与 FairPlay 等 DRM 方案配合使用。

## 四、第三层：商业 DRM

DRM 依托浏览器的 EME（Encrypted Media Extensions）接口和设备内的 CDM 模块，在可信环境中解密，密钥不会暴露给 JavaScript。主流方案有三种：

| 方案 | 主要覆盖平台 |
|---|---|
| Google Widevine | Chrome、Android、部分智能电视 |
| Apple FairPlay | Safari、iOS、tvOS |
| Microsoft PlayReady | Edge、Windows、部分智能电视 |

要覆盖全平台，往往需要多 DRM 并存，并配合 CENC/CMAF 封装，接入和授权成本都更高。影视版权方通常会明确要求 DRM；企业培训类场景则可以按需评估。

## 五、第四层：防盗链与水印

### URL 鉴权与防盗链

- **URL 签名**：播放地址带上过期时间和签名，过期后失效，防止地址被转发长期使用；
- **Referer / 域名白名单**：只允许自有站点或 App 引用；
- **IP 黑白名单与频率限制**：拦截异常的批量请求。

### 数字水印

- **明水印**：在画面上叠加用户昵称、ID 或手机号片段，可以设置随机位置跑动，降低被裁剪的可能；
- **暗水印**：肉眼不可见，可在泄露的视频中提取用户信息，适合对版权要求更高的内容。

## 六、播放端的加固措施

服务端做得再好，播放端也是攻击者重点关注的地方。常见的加固手段包括：

- **限制并发播放**：同一账号同时在多台设备播放时进行提示或拦截，减少账号共享；
- **检测调试与录屏环境**：在 App 内检测模拟器、调试工具和部分录屏软件，发现后暂停播放；
- **移动端禁止截屏录屏**：Android 可以通过系统提供的安全窗口标记禁止截屏，iOS 可以检测屏幕录制状态并作出响应；
- **离线缓存加密**：允许离线观看时，缓存文件必须加密存储，并绑定设备和有效期。

这些措施同样不能保证万无一失，但能把大部分“顺手下载”的行为挡在门外。

## 七、运营层面的配合

技术之外，管理措施同样重要：在用户协议中明确禁止传播课程内容；对异常播放行为（例如短时间内大量拉取分片）设置告警；发现泄露后通过水印定位账号，并按协议处理。技术与制度结合，才能形成完整的内容保护体系。

## 八、按场景的组合建议

| 场景 | 推荐组合 |
|---|---|
| 企业内训、内部资料 | HTTPS + 分片加密 + 登录鉴权 + 明水印，可对接企业统一身份认证 |
| 知识付费课程 | 分片加密 + 一次性播放凭证 + URL 签名 + 跑马灯水印 |
| 影视版权内容 | 多 DRM + CMAF + 暗水印 |

如果团队不想自研整套体系，可以选择内置视频加密能力的点播平台。选型时可以要求供应商逐项说明 AES 加密、URL 鉴权、视频水印、IP 黑白名单与操作日志等能力，并对照上面的四层防线确认。
